# J-space write path (August 2026): a preregistered negative

Can a skill held in context be written into the weights by reaching the same workspace state
through the weights? No. Five configurations, forty trained models, install rate 0.0% at every
drift magnitude; the better the state match, the same zero. Ordinary fine-tuning installs 92% at a
far worse state match. The objective selected against the outcome.

Start with `RESULT-phase3-jspace.md`, then `CONTEXT.md`, `WHY.md`, `DECISIONS.md`. Preregistrations
in `PREREG-*.md` and `out/IGNITION-CRITERION-v2.md`. Large artefacts (lens tensors, sweep logs,
pulled model outputs) are omitted here for size; scripts in `scripts/` regenerate them.
Coordinate system: Anthropic's global-workspace paper (Transformer Circuits, July 2026).
